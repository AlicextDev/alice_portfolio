Portfólio interativo pessoal desenvolvido para destacar projetos, vivências e trajetória nas áreas de **Ciência de Dados**, **Automação de Processos (RPA)** e **Desenvolvimento de Software Full Stack**.

O projeto conta com uma identidade visual moderna, paleta refinada em tons de rosa chá e vinho, suporte bilíngue em tempo real e microinterações dinâmicas.

---

## ✨ Funcionalidades Principais

* **Internacionalização (i18n):** Alternância instantânea de idioma entre **Português (PT-BR)** e **Inglês (EN)** sem recarregar a página, utilizando atributos de dados customizados (`data-pt` e `data-en`).
* **Microinterações e Efeitos Visuais:**
  * *Spotlight* sutil que acompanha dinamicamente a posição do cursor.
  * Efeito de partículas e brilhos cintilantes flutuando pelo plano de fundo.
  * Rastro suave de pequenas estrelas que se dissipam ao movimentar o mouse.
  * Animações de entrada fluidas (*scroll reveal*) via `IntersectionObserver`.
* **Filtro Dinâmico de Projetos:** Filtragem rápida de trabalhos por categorias (*Todos*, *Dados*, *Desenvolvimento* e *Automação*).
* **Carrossel Interativo de Vivências:** Galeria estilo polaroid para eventos, hackathons e rotina de estudos com controles de navegação responsivos.
* **Design Responsivo & Acessível:** Layout fluido adaptado para desktop, tablets e smartphones, com suporte nativo a `prefers-reduced-motion`.

## 🛠️ Tecnologias Utilizadas

* **HTML5 Semântico:** Estruturação otimizada para SEO e acessibilidade.

## 🚀 Como Executar Localmente

Como o projeto é construído em tecnologias web estáticas, você não precisa instalar dependências ou gerenciadores de pacotes (como npm ou yarn):

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/AlicextDev/portfolio.git
   cd portfolio
   ```

2. **Abra o arquivo `index.html`:**
   * Dê um duplo clique no arquivo `index.html` para abri-lo diretamente no seu navegador padrão; ou
   * Utilize a extensão **Live Server** no [VS Code](https://code.visualstudio.com/) para recarregamento automático durante edições.

## 🌐 Publicação (Deploy)

O portfólio pode ser publicado gratuitamente em plataformas de hospedagem estática:

* **GitHub Pages:**
  1. Vá até as configurações do seu repositório no GitHub (`Settings` > `Pages`).
  2. Em **Branch**, selecione `main` (ou `master`) e a pasta `/root`.
  3. Salve para gerar o link público imediato.
* **Vercel** ou **Netlify:** Basta conectar sua conta ao GitHub e importar o repositório diretamente com um clique.
